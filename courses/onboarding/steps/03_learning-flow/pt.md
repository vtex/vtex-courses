# Fluxo de aprendizado

## Cursos

Nossos cursos são estruturados para que cada estudante aprenda no seu próprio ritmo.  
Cada curso é dividido em diversos passos, e cada passo inclui uma atividade específica.  

Abaixo, você pode ver um exemplo de página inicial de um curso. Ela apresenta o título, uma breve descrição do conteúdo e a lista de passos com suas respectivas descrições. Para começar, basta clicar no primeiro passo!  

![](https://user-images.githubusercontent.com/19495917/92601628-76715d80-f283-11ea-91ff-545874e821e0.png)

Ao final de cada passo, pode haver um _link_ para o **gabarito do curso** — uma página que contém todos os arquivos do projeto que precisam ser alterados naquele passo específico.  

![](https://user-images.githubusercontent.com/19495917/92601642-78d3b780-f283-11ea-9428-a7bb39e9d7bc.png)

Clicando nesse _link_, você será redirecionado para uma página como esta:  

![](https://user-images.githubusercontent.com/19495917/92601645-796c4e00-f283-11ea-906f-3d9308de492d.png)

> 📘 Cada arquivo que precisa ser alterado em um passo terá uma aba correspondente, com o nome do arquivo como título.

## Sugestões

Os passos de cada curso foram planejados para construir o conhecimento de forma progressiva e contínua.  
Por isso, **evite ao máximo pular etapas** — isso garante que todos os conceitos necessários sejam apresentados no momento certo.  

> 📘 _TL;DR_: Siga a ordem dos passos, evite pular etapas!  

Para acompanhar a evolução dos desenvolvedores, monitoramos métricas de progresso. Isso nos permite identificar dificuldades, oferecer suporte e avaliar o tempo médio de conclusão de cada curso, ajudando-nos a melhorar continuamente.  

👉 Para manter essas métricas válidas:  
- Sempre avance para o próximo passo usando o botão no fim do passo atual.  
- No **último** passo, não esqueça de clicar no botão **Finalizar curso**.  

* Botão para ir para o próximo passo:  
  ![](https://user-images.githubusercontent.com/19495917/92601647-796c4e00-f283-11ea-9fec-68f35c130971.png)  

* Botão para finalizar o curso:  
  ![](https://user-images.githubusercontent.com/19495917/92601649-7a04e480-f283-11ea-95b8-3fe50f294160.png)

> 📘 _TL;DR_: Use sempre os botões ao final de cada passo para avançar. No último passo, clique em **Finalizar** para concluir o curso.
